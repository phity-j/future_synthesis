## AI時代に「仕事」と「所得」の関係はどう変わるのか

AIとロボットの普及で、人間の労働需要が減る可能性が指摘されています。その際、所得の仕組みをどう設計するかが、社会の自由度を左右します。

この記事では、AI時代の所得保障を3つのシナリオに分けて整理し、個人がキャリアで取れる備えを示します。他の媒体の記事と異なり、制度の比較と将来シナリオに絞って解説します。

## 結論

- AI時代の分かれ目は「仕事の有無」ではなく、所得保障の設計とAI基盤の所有にある
- ベーシックインカムが自由につながるか管理につながるかは、条件とデータの扱い次第
- 個人は、手段の分散・成果物の保全・目的の言語化で備えられる

## 用語の整理


| 用語 | 意味 |
| ------------- | ------------------------------ |
| ベーシックインカム（BI） | 国民に一定額を支給する制度 |
| AI基盤 | AIモデル、計算資源、クラウド、データの総称 |
| デジタル封建制 | 生産基盤を握る少数者に社会が依存する構造を指す、筆者の呼び方 |
| ナッシュ均衡 | 各自が合理的に選んだ結果、誰も一人では選択を変えられない状態 |
| 単一障害点 | 一か所の不具合で全体が止まる弱点 |


## AI時代の所得保障：3つのシナリオ


| シナリオ | 制度の特徴 | AI基盤の所有 | 個人への影響 |
| ---- | ---------------- | ------------ | ------------ |
| 分散型 | 無条件のBI、データは本人が管理 | 複数の事業者・公共が分担 | 時間と選択の自由が広がる |
| 条件型 | 活動を条件にしたBI | 一部の事業者が主導 | 形式的な「仕事」が残る |
| 管理型 | 行動データに連動する給付 | 少数の企業に集中 | 生活全体が評価される |


どのシナリオに進むかは、技術ではなく制度の選択で決まります。分かれ目になる確認項目は次の4点です。

- データの所有者は誰か
- 利用目的は限定されているか
- 本人は拒否できるか
- 給付と結びつくか

## なぜ悪意がなくても管理型に進むのか

企業は利益のために基盤を囲い込み、政府は安全保障のために依存し、市民は便利さのために利用します。全員が合理的でも、結果として依存が強まります。この構造は、競争の仕組みを見直すことでしか変えられません。競争構造の詳細は、[ナッシュ均衡から予定調和へ](https://phity.net/ai-nash-leibniz)で解説しています。

## 個人ができる3つの備え


| 備え | 具体策 | 効果 |
| ------ | ------------------- | ---------- |
| 手段の分散 | 複数のAIサービスを使える状態にする | 一社への依存を下げる |
| 成果物の保全 | データや成果物を持ち出せる形で保存する | 乗り換えが可能になる |
| 目的の言語化 | AIに聞く前に目的を書き出す | 手段に流されない |


特に、AIを使い始めた方ほど、一つのサービスに業務を寄せやすくなります。複数手段の確保は、キャリアの安全性に直結します。依存と判断の関係は、[AIに任せすぎると何が起きるか](https://phity.net/ai-brain-lazy)も参考になります。

## よくある質問（FAQ）

AIで仕事がなくなったら、ベーシックインカムは必要ですか。  
労働需要が大きく減る場合、所得保障の議論は避けられません。ただし、無条件型か、データ連動型かで、人間への影響は大きく異なります。

デジタル封建制とは何ですか。  
生産に必要なAI基盤を少数の企業が握り、社会全体がそこに依存する構造を指す、筆者の呼び方です。歴史上の封建制と同一視するものではありません。

AI時代のキャリアで最初にすべきことは何ですか。  
複数のAIを使える状態にすること、成果物を手元に残すこと、目的を言語化すること、の3点です。
